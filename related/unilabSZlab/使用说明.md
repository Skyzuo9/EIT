# 实验室 3D 贴图资产生成器｜一键团队版

版本：1.2.0  
发布日期：2026-07-25

## 同事只需三步

1. 完整解压 ZIP。
2. 用 Codex 打开整个解压后的根目录。
3. 打开 `复制到Codex的提示词.txt`，把方括号示例替换为真实仪器名称，然后整段粘贴给 Codex。

请写“厂家 + 精确型号”，每行一台。不要移动或单独复制包内文件；Skill 位于隐藏目录 `.agents/skills`。

## Codex 会自动完成

- 创建本地配置文件并安装锁定依赖。
- 把提示词里的仪器名称写入 `待生成3D资产仪器清单.xlsx`。
- 初始化可恢复的本地任务状态。
- 研究准确型号、多视角图片、真实尺寸与来源。
- 在提示词授权的首轮 credits 上限内生成带 PBR 高清贴图的 GLB。
- 生成 STL，执行几何与视觉质检。
- 仅在所有强制检查通过时发布到 `模型资产/`。

重复粘贴同一提示词会恢复已有状态，不会重复初始化。若解压目录已经处理过不同的仪器，Codex 会拒绝覆盖；请继续原任务或解压一份全新副本。

## API Key 的安全边界

压缩包不包含任何 API Key，也不会要求把 Key 粘贴进聊天。

- 如果公司已通过系统环境或密钥管理工具配置 `MESHY_API_KEY`，同事确实只需上述三步。
- 如果尚未统一配置，第一次运行时 Codex 会创建 `asset_pipeline/.env` 并给出它的本地路径。同事只需在本机填写一次 `MESHY_API_KEY=` 后面的值，再让 Codex 继续。
- `BRAVE_SEARCH_API_KEY` 可选；未配置时流水线使用无 Key 的检索后备。

不要把 `.env` 上传到飞书、Git、共享盘或聊天。不要把真实 Key 写进 Excel 或提示词。将共享 Key 直接打进 ZIP 虽然少一步，但无法控制扩散和撤销，不建议这样做。

## 费用授权

包内提示词只授权每台仪器一次、最多 30 Meshy credits 的首轮生成，总上限为有效仪器数乘以 30。以下情况会暂停，不会自动扣费：

- 没有本地 Meshy Key。
- 准确型号置信度不足。
- 宽/深/高尺寸不完整或没有来源链接。
- 预计首轮 credits 超过提示词上限。
- 需要创建第二个 Meshy 任务。
- 强制几何或视觉质检失败。

付费重试必须由使用者另行明确授权。

## 输出

通过全部门禁后，新资产位于 `模型资产/`：

- `.glb`：PBR 贴图，米制，Z-up。
- `.stl`：仅几何，毫米制，Z-up；STL 格式本身不支持贴图。

本包不含任何作者已经生成的资产、历史数据库、审批记录、credits 记录或密钥。每位同事应使用自己的解压副本，不要多人同时读写共享目录中的同一个 SQLite 状态文件。

## Skill 没显示怎么办

确认 Codex 打开的根目录同时包含：

```text
.agents/
asset_pipeline/
模型资产/
复制到Codex的提示词.txt
待生成3D资产仪器清单.xlsx
```

然后新建一个 Codex 任务；仍未出现时重启 Codex。
